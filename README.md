# CPT 内容发布活动日历

使用原生 HTML、CSS 和 JavaScript 实现的 **GitHub 风格年度内容活动热力图**。适合演示 WordPress 自定义内容类型（CPT）的按日期记录展示方式。

> 当前版本是独立的前端静态演示，**尚未连接 WordPress 或 REST API**；日期及内容来自 JavaScript 生成的模拟数据。不会自动读取真实的 WordPress 文章。

## 在线预览与本地运行

下载或克隆仓库后，直接使用 Chrome 等现代浏览器打开根目录 `index.html` 即可，无需安装依赖或启动服务器。也可以开启 GitHub Pages，将发布源设为主分支根目录进行在线展示。

## 功能

- 按年显示日期热力图，自动处理 365/366 天与闰年。
- 不同颜色表示当天记录数量（0、1、2、3、4 条及以上）。
- 鼠标悬停查看日期、数量及标题；键盘焦点也能查看提示。
- 点击某天弹出当天记录，进一步查看单篇演示详情；`Esc` 可关闭。
- 按内容类型和年份筛选，自动统计记录条数和活跃天数。
- 手机端支持横向滚动，点击日期查看记录。
- Hover 不使用外部描边，避免与提示框发生视觉重叠。

## 演示数据说明

`assets/js/app.js` 中的 `makeDemoData()` 为当前年份和上一年生成可重复的模拟内容。真实可选年份由数据中的日期自动提取，并且始终包含当前年份。因此程序可跨年运行，但**没有数据的年份不会凭空出现历史记录**。

每条记录的主要字段：

```json
{
  "id": 1,
  "date": "2026-04-20",
  "type": "product",
  "title": "产品资料更新",
  "excerpt": "内容摘要",
  "content": "演示详情",
  "url": "#"
}
```

`date` 使用本地日历格式 `YYYY-MM-DD`，`type` 对应 `types` 映射中的内容类型。当前详情弹窗读取 `content` 文本，`url` 仅为预留字段，**本版本没有实现跳转到 WordPress 文章**。

## 将来接入 WordPress 的建议

建议保留前端的日历渲染逻辑，单独通过 WordPress REST API 获取**选定年份和内容类型**的数据，再提供给日历。后端优先返回精简字段，避免一次请求多年文章正文；详情可按需获取。公开页面应仅展示允许公开的内容，不可将未公开文章通过接口泄露。

本仓库**不是 WordPress 插件**，当前没有短代码、后台设置页或 CPT 自动读取功能。上述功能可在验证静态版效果后独立开发。

## 技术栈

- HTML5
- CSS3（Grid、响应式、Hover 提示框）
- 原生 JavaScript（日期处理、筛选、弹窗）
- 无 jQuery、Bootstrap、FullCalendar 或其他第三方运行依赖
